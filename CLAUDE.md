# CICLO - Claude Code Guidelines

## What is this?

CICLO is a real-time multiplayer game simulating the Grupalia group credit experience. Players join rooms, pick business types, choose loan sizes, and navigate weekly payment cycles with hidden payments, business events, secret objectives, and solidarity mechanics. Built as an empathy-focused team-building exercise for Grupalia employees.

## Stack

- **Frontend:** React 19 + TypeScript + Vite + Tailwind CSS 4 + shadcn/ui
- **Backend/Realtime:** SpacetimeDB v2 (TypeScript server module)
- **Package manager:** pnpm
- **Deploy target:** SpacetimeDB Maincloud (ciclo-game)
- **Domain:** ciclo.datadiego.com
- **No auth:** Room code in URL is the "auth"

## SpacetimeDB Integration

### Current state
- **ALL screens** are fully wired to SpacetimeDB (lobby, game, results)
- 10 tables: game, player, payment, weekResult, gameEvent, chatMessage, customSticker, businessEvent, solidarioTransfer, secretObjective

### Key patterns
- Reducers are deterministic: no `Math.random()`, no `Date.now()` — use `ctx.timestamp`
- Code + group name are generated client-side and passed to `createGame` reducer
- Use `useTable(tables.game)` etc. from `spacetimedb/react`
- Call reducers via `conn.reducers.someReducer({ param: value })` (object syntax, NOT positional)
- Identity comparison: `identity.toHexString() === other.toHexString()`

### Commands
```bash
# Publish server module
cd spacetimedb && echo "y" | spacetime publish ciclo-game --module-path .

# Regenerate client bindings after server changes
spacetime generate --lang typescript --out-dir ../src/module_bindings --module-path .

# View server logs
spacetime logs ciclo-game
```

## Design Decisions

### App Separation (STRICT)
- **WhatsApp** = PURELY social. Chat, stickers, Asesora bot hints, system messages. NO buttons, NO game mechanics.
- **Grupalia** = ALL game mechanics. Payments, business events, secret objective, solidario, ranking.

### Three Pillars (Catan-inspired)
1. **Chance**: Business events per player per week (deterministic, business-type specific)
2. **Skill**: Payment decisions (proportional to loan size) + solidario transfers ($200, private)
3. **Secret objectives**: Hidden goals assigned at start, revealed at end with bonuses

### Credit Model
- Loan sizes: Pequeño ($2,000), Mediano ($3,500), Grande ($5,000)
- **Tasa: $75 pesos por cada mil** (Grupalia standard range 69-82)
- Weekly payment = ceil((credit + credit × 75/1000) / weeksTotal)
- All payments proportional to player's own weeklyPayment

### Other
- **Symmetric play** — no presidenta, all players equal
- **Hidden payments** — nobody sees who paid, Asesora gives escalating hints
- **Time of day** — action phase cycles Lunes→Viernes with visual background tints
- **Spanish language** with proper accents (target: Grupalia Mexico team)
- **Mobile-first** with Android phone frame

## Game Flow

1. Creator opens app → picks mode (4/8/16 weeks) → gets room code + invite link
2. Guests open invite link (`?room=CODE`) → enter name → pick pronoun → pick business → pick loan size
3. Creator starts cycle → secret objectives assigned, week 1 events generated
4. Each week: Action (60s, Lunes→Viernes) → Results (15s, Noche) → Rest (15s, Domingo)
5. During action: pay in Grupalia, chat in WhatsApp, Asesora gives hints, share events, send solidario
6. Final screen: graduation status + ranking + secret objective reveal
