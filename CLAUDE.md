# CICLO - Claude Code Guidelines

## What is this?

CICLO is a real-time multiplayer game simulating the Grupalia group credit experience. Players join rooms, pick business types, and navigate weekly payment cycles. Built as a team-building exercise for Grupalia.

## Stack

- **Frontend:** React 19 + TypeScript + Vite 8 + Tailwind CSS 4
- **Backend/Realtime:** SpacetimeDB v2 (TypeScript server module)
- **Package manager:** pnpm
- **Deploy target:** SpacetimeDB Maincloud (free hosted)
- **No auth:** Room code in URL is the "auth"

## SpacetimeDB Integration

### Current state (Sprint 2)
- **Lobby** is fully wired to SpacetimeDB (create/join/name/business/start)
- **Game + Results** still use local `useGameStore` — migration planned

### Key patterns
- Reducers are deterministic: no `Math.random()`, no `Date.now()` — use `ctx.timestamp`
- Code + group name are generated client-side and passed to `createGame` reducer
- Use `useTable(tables.game)` and `useTable(tables.player)` from `spacetimedb/react`
- Call reducers via `conn.reducers.someReducer({ param: value })` (object syntax, NOT positional)
- Identity comparison: `identity.toHexString() === other.toHexString()`

## Design Decisions

- **WhatsApp-style UI** for familiarity — all interactions via chat bubbles and buttons
- **Mobile-first** with Android phone frame in lobby, responsive game screen
- **Spanish language** for in-game text (target audience: Grupalia Mexico team)
- **Bot players** for dev testing (local-only, not synced to SpacetimeDB)
- **No free-text game decisions** — buttons only to reduce complexity
- **Presidenta selection** is deterministic (server timestamp modulo player count)

## Game Flow

1. Creator opens app → picks mode → gets room code + invite link
2. Guests open invite link (`?room=CODE`) → see group name → enter name → pick business
3. Creator starts cycle → all transition to Game screen
4. 4-16 weeks of: Action (60s) → Results (15s) → Rest (15s)
5. Final screen: graduation status + standings
